## 为什么选择 JustFocus？

大多数网站拦截工具充斥着广告、强制登录和侵入式追踪。JustFocus 不同 — 它只做一件事并且做到最好：**屏蔽干扰你的网站**。

| 优势 | 说明 |
|------|------|
| 🎯 **单一职责** | 屏蔽干扰网站，仅此而已。没有臃肿功能。 |
| 🔒 **零追踪** | 无分析、无账号、无任何数据收集 |
| ⚡ **轻量** | 总体积不到 50KB，无框架、无依赖 |
| 🕐 **临时放行** | 需要 5 分钟？临时放行无需删除站点 |
| 🔄 **全局开关** | 一键暂停所有屏蔽 — 午休、周末 |
| 🌍 **6 种语言** | 英文、中文、日文、德文、西班牙文、法文 |

## 功能特性

| 功能 | 说明 |
|------|------|
| 🚫 **自定义黑名单** | 添加任意域名屏蔽 — 支持精确和泛域名匹配 |

## 安装方法

### 从源码安装（开发者模式）

1. 克隆或下载本仓库
2. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
3. 开启右上角**开发者模式**
4. 点击**加载已解压的扩展程序**，选择 `just-focus` 文件夹
5. 点击工具栏中的 🎯 JustFocus 图标即可开始

### 构建（压缩 + 打包）

```bash
npm install
npm run build
```

输出：`dist/` 文件夹 + `just-focus-v1.0.0.zip`，可直接上传 Chrome Web Store。

## 使用方法

### 屏蔽网站

1. 点击工具栏中的 JustFocus 图标
2. 输入域名（如 `youtube.com`）
3. 按回车或点击 **+**
4. 完成 — 访问该网站将跳转到专注提示页面

### 临时放行

1. 访问被屏蔽页面时，点击 **"临时放行 5 分钟"**
2. 立即跳转到该网站
3. 5 分钟后自动恢复屏蔽

### 暂停所有屏蔽

- 将弹窗顶部的开关切换到 OFF
- 所有网站立即解除屏蔽
- 切换回 ON 重新启用

## 隐私保护

- **declarativeNetRequest** — 使用声明式规则拦截网站，不读取页面内容
- **storage** — 本地保存黑名单，不上传数据
- **alarms** — 管理临时放行计时器，无后台追踪
- **activeTab** — 仅在操作扩展时访问当前标签页
- 不申请 `<all_urls>` 主机权限。无追踪、无分析、无外部连接
