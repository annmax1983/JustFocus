## 功能特性

| 功能 | 说明 |
|------|------|
| 🚫 **自定义屏蔽列表** | 添加任意域名进行屏蔽，支持精确和通配符匹配 |
| 🔄 **全局开关** | 一键切换所有屏蔽的开/关状态 |
| ⏱️ **5 分钟临时解锁** | 临时访问被屏蔽的网站，5 分钟后自动重新屏蔽 |
| 💾 **同步存储** | 屏蔽列表在 Chrome 设备间同步 |
| 🛡️ **MV3 原生** | 使用 declarativeNetRequest，无旧版 API |
| 🌐 **自动语言** | 检测浏览器语言，默认英文 |
| 📋 **完整列表页** | 管理所有屏蔽站点、修改时长、导出与导入 |
| ⭐ **高级版** | 不限站点数量 + 导出/导入（一次性 VKT 高级版许可证） |

## 安装

1. 克隆或下载本仓库
2. 打开 `chrome://extensions/`
3. 开启**开发者模式**
4. 点击**加载已解压的扩展程序**，选择 `just-focus` 文件夹
5. 点击工具栏中的 🎯 JustFocus 图标

---

## 使用方法

### 屏蔽网站

1. 点击 JustFocus 图标
2. 输入域名（如 `youtube.com`）
3. 按回车或点击 **+**
4. 完成 — 访问该网站时将跳转到专注提醒页面

### 临时解锁

1. 跳转到被屏蔽页面时，点击 **"解锁 5 分钟"**
2. 立即跳转到该网站
3. 5 分钟后自动恢复屏蔽

### 暂停所有屏蔽

- 将弹窗顶部的开关切换到 OFF
- 所有网站立即解除屏蔽
- 切换回 ON 重新启用

## 隐私

- **declarativeNetRequest** — 使用声明式规则屏蔽网站，不读取页面内容
- **storage** — 本地保存屏蔽列表，不上传数据
- **alarms** — 管理临时解锁定时器，无后台追踪
- **许可证（可选）** — 仅当您激活付费许可证时，会向 `api.annmax1983.com` 发送设备指纹和浏览器元数据，用于激活/校验许可证。绝不包含您的屏蔽列表、浏览历史或个人数据。
- 使用 `<all_urls>` 主机权限仅用于 declarativeNetRequest 屏蔽规则，授权服务器仅用于付费激活。无追踪，无分析，免费用户的数据永远不会离开设备。
