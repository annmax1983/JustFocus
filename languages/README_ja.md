## JustFocusを選ぶ理由？

ほとんどのサイトブロッカーは広告、強制登録、侵襲的なトラッキングで膨れ上がっています。JustFocusは違います — 一つのことだけを、きちんとやります：**邪魔なサイトをブロックする**。

| 利点 | 詳細 |
|------|------|
| 🎯 **単一目的** | 邪魔なサイトをブロック。それだけ。無駄なし。 |
| 🔒 **ゼロトラッキング** | 分析なし、アカウントなし、データ収集なし |
| ⚡ **軽量** | 合計50KB未満。フレームワークなし、依存なし。 |
| 🕐 **一時バイパス** | 5分必要？サイトを一時的にアクセス可能に |
| 🔄 **グローバル切替** | 一つのスイッチで全ブロックを一時停止 |
| 🌍 **6言語** | 英語、中国語、日本語、ドイツ語、スペイン語、フランス語 |

## 機能

| 機能 | 説明 |
|------|------|
| 🚫 **カスタムブロックリスト** | 任意のドメインをブロック — 正確一致とワイルドカードに対応 |
| 🔄 **グローバルON/OFF** | 全ブロックを即座に切替 |
| ⏱️ **5分バイパス** | ブロックされたサイトを5分間一時アクセス、自動再ブロック |
| 💾 **同期ストレージ** | ブロックリストがChromeデバイス間で同期 |
| 🛡️ **MV3ネイティブ** | declarativeNetRequest使用 — レガシーAPIなし |
| 🌐 **自動言語** | ブラウザ言語を検出、未一致時は英語 |

## インストール

### ソースから（デベロッパーモード）

1. リポジトリをクローンまたはダウンロード
2. ブラウザの拡張機能ページを開く：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
3. **デベロッパーモード**を有効化
4. **パッケージ化されていない拡張機能を読み込む**をクリックし`just-focus`フォルダを選択
5. ツールバーの 🎯 JustFocus アイコンをクリック

### ビルド（圧縮 + パッケージ）

```bash
npm install
npm run build
```

出力：`dist/` フォルダ + `just-focus-v1.0.0.zip`

## 使い方

### サイトをブロック

1. ツールバーのJustFocusアイコンをクリック
2. ドメインを入力（例：`youtube.com`）
3. Enterを押すか **+** をクリック
4. 完了 — そのサイトにアクセスすると集中リマインダーページにリダイレクト

### 一時バイパス

1. ブロックページで **「5分間バイパス」** をクリック
2. 即座にサイトにリダイレクト
3. 5分後に自動的にブロック復帰

## プライバシー

- **declarativeNetRequest** — 宣言ルールでサイトをブロック。ページ内容は読み取りません
- **storage** — ブロックリストをローカル保存。データはアップロードされません
- **alarms** — 一時バイパスタイマーを管理。バックグラウンド追跡なし
- **activeTab** — 拡張機能操作時のみ現在のタブにアクセス
- `<all_urls>` ホスト権限なし。追跡なし。分析なし。外部接続なし。
