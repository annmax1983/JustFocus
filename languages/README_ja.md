気を散らすウェブサイトをブロックして集中を維持する軽量ブラウザ拡張機能。ミニマル、高速、プライバシー優先。

> Chromium ベース · Manifest V3 · 最小権限 · ローカル優先 · ゼロ追跡

---

## 機能

| 機能 | 説明 |
|------|------|
| 🚫 **カスタムブロックリスト** | ドメインを追加してブロック |
| 🔄 **グローバルオン/オフ** | すべてのブロックを一括切り替え |
| ⏱️ **5分バイパス** | 一時的にサイトにアクセス、5分後に自動再ブロック |
| 💾 **同期ストレージ** | ブロックリストをChromeデバイス間で同期 |
| 🛡️ **MV3ネイティブ** | declarativeNetRequest使用 |
| 📋 **完全リストページ** | 全サイト管理、期間編集、エクスポート・インポート |
| ⭐ **プレミアム** | 無制限サイト + エクスポート/インポート（一回限りのVKTプレミアムライセンス） |

---

## 無料版 vs プレミアム

| プラン | ブロックサイト数 | エクスポート / インポート |
|--------|------------------|---------------------------|
| **無料版** | 有効なサイト最大10件 | — |
| **⭐ プレミアム** | 無制限 | ✅ 対応 |

無料版は**有効なブロックサイトを最大10件**まで登録できます。無制限のサイトとブロックリストの**エクスポート / インポート**をご利用いただくには、**VKTプレミアム**ライセンスの有効化（一回限りの購入）が必要です。

- 🛒 ライセンスを取得：`https://www.annmax1983.com/checkout.html?plugin=justfocus`
- ⚙ 有効化：JustFocusポップアップを開く → **⚙ / 🔒**ボタンをクリック → ライセンスキーを入力。

> ライセンス有効化は**任意**です。無料版はアカウントや登録、キーなしで完全に動作します。

## インストール

1. リポジトリをクローンまたはダウンロード
2. `chrome://extensions/`を開く
3. **デベロッパーモード**を有効化
4. **パッケージ化されていない拡張機能を読み込む**
5. ツールバーの🎯 JustFocusアイコンをクリック

---

## 使い方

### サイトをブロック

1. JustFocusアイコンをクリック
2. ドメインを入力（例：`youtube.com`）
3. Enterまたは**+**をクリック
4. 完了 — サイト訪問時にフォーカスページにリダイレクト

### 一時バイパス

1. ブロックページで**「5分バイパス」**をクリック
2. 即座にサイトにアクセス
3. 5分後に自動的にブロック復帰

## プライバシー

- 追跡なし、分析なし。無料版は完全にローカルで動作
- ブロックリストと設定はすべてブラウザ内にローカル保存
- **ライセンス（任意）** — 有料ライセンスを有効化した場合のみ、デバイスフィンガープリントとブラウザメタデータを `api.annmax1983.com` に送信してライセンスを有効化・検証します。ブロックリストや閲覧履歴、個人データを含むことはありません。
- 無料ユーザーのデータがデバイスの外に出ることはありません。
