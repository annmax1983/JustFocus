# JustFocus

[English](../README.md) | [中文](README_zh.md) | [日本語](README_ja.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [Français](README_fr.md)

集中力を維持するために、気が散るWebサイトをブロックする軽量ブラウザ拡張機能です。ミニマルで高速、プライバシーを重視しています。

> Chrome / Edge / Firefox · Manifest V3 · 最小限の権限 · ローカル優先 · トラッキングなし

---

## JustFocusの特長

ほとんどのサイトブロッカーは、広告や強制登録、侵襲的なトラッキングで肥大化しています。JustFocusは違います — **気が散るサイトをブロックする**、たった一つのことだけを、しっかりやります。

| 特長 | 詳細 |
|-----------|--------|
| 🎯 **単一目的** | 気が散るサイトをブロックするだけ。余計なものなし。 |
| 🔒 **トラッキングなし** | アナリティクスもアカウントも不要。無料版は完全にローカル処理 — データがデバイスの外に出ることはありません |
| ⚡ **軽量** | 小さなフットプリント、フレームワーク不使用、依存関係なし |
| 🕐 **一時バイパス** | 5分だけ必要な場合、サイトを削除せずに一時的にアクセス可能 |
| 🔄 **グローバルトグル** | 一つのスイッチですべてのブロックを一時停止 — 昼休みや週末に |
| 🌍 **6言語対応** | 英語、中国語、日本語、ドイツ語、スペイン語、フランス語 |

## 機能一覧

| 機能 | 説明 |
|---------|-------------|
| 🚫 **カスタムブロックリスト** | 任意のドメインを追加 — すべてのサブドメインが自動的にブロックされます |
| 🔄 **グローバルON/OFF** | すべてのブロックを即座にON/OFF |
| ⏱️ **5分バイパス** | ブロックされたサイトに5分間一時アクセス、自動的に再ブロック |
| 💾 **同期ストレージ** | ブロックリストが Chrome / Edge / Firefox 間で同期 |
| 🛡️ **MV3ネイティブ** | declarativeNetRequestを使用 — レガシーAPI不使用、ストアフレンドリー |
| 🌐 **自動言語検出** | ブラウザの言語を検出し、デフォルトは英語 |
| 📋 **フルリストページ** | ブロックしたすべてのサイトを管理、期間の編集、エクスポート＆インポート |
| 🔑 **パスワード保護** | オプションのローカルパスワード：ブロック解除・サイト削除・ブロック停止にはパスワードが必要。忘れた場合は復元できません |
| ⭐ **Premium** | 外科的ブロック — Shorts・リール・おすすめフィードだけを非表示にし、サイトの他機能はそのまま（買い切りのVKT Premiumライセンス） |

## 無料版 vs Premium

| プラン | ブロックサイト数 | エクスポート／インポート | 外科的ブロック |
|------|---------------|-----------------|--------------|
| **無料版** | 無制限 | 対応 | YouTube Shorts のみ |
| **⭐ Premium** | 無制限 | 対応 | 対応12サイトすべて |

サイトのブロックは**無制限・完全無料**です。**Premiumでは「外科的ブロック」が使えます** — 依存しやすい部分（Shorts・リール・おすすめフィード）だけを非表示にし、サイトの他の機能はそのまま使えます。YouTube、Instagram、TikTok、Facebook、Reddit、X、Pinterest、Threads、LinkedIn、Snapchat、VK、小紅書に対応。

> YouTube Shorts のブロックは全ユーザー無料、その他のサイトには Premium ライセンスが必要です。

- 🛒 ライセンス取得：`https://www.annmax1983.com/checkout.html?plugin=justfocus`
- ⚙ 有効化：JustFocusポップアップを開き、**⚙ / 🔒**ボタンをクリックしてライセンスキーを入力します。

> ライセンス有効化は**オプション**です。無料版はそれなしで完全に動作します — アカウント登録もライセンスキーも不要です。

## 対応ブラウザ

| プラットフォーム | ブラウザ | ステータス |
|---------|--------|--------|
| デスクトップ | Google Chrome | ✅ 完全対応 |
| デスクトップ | Microsoft Edge | ✅ 完全対応 |
| デスクトップ | その他のChromium系ブラウザ（Brave、Vivaldi、Opera、Chromium） | ✅ 動作するはずです |
| Android | **Android版 Chrome** | ❌ 不可 — Android版 Chrome は拡張機能に一切対応していません |
| Android | Microsoft Edge Canary | ⚠️ 実験的な拡張機能対応。対応数が少なく不安定 |
| Android | Chrome ウェブストアの拡張機能を読み込めるChromium系フォーク（Quetta、Yandex など） | ⚠️ 非公式。動くはずですが未検証 |
| Android | Firefox for Android | ❌ 不可 — JustFocus は Chromium MV3（`declarativeNetRequest`）で作られており、AMO では配布していません |
| iOS | すべて | ❌ 不可 — Safari 以外の iOS ブラウザは拡張機能に対応していません |

> **結論：** これはデスクトップ向けブラウザ拡張機能です。スマートフォンへのインストールはサポートしていません — Android版 Chrome は拡張機能を受け付けず、回避策（Edge Canary、サードパーティの Chromium フォーク）は実験的で、サポートできません。ブロック機能はデスクトップ版の Chrome / Edge / Firefox で動作します。

## 使い方

### Webサイトをブロックする

1. ツールバーのJustFocusアイコンをクリックします
2. 入力フィールドにドメイン（例：`youtube.com`）を入力します
3. Enterキーを押すか**＋**をクリックします
4. 完了 — そのサイトへのアクセスが集中リマインダーページにリダイレクトされます

### 一時的にバイパスする

1. ブロックページに到達したら、**「5分間バイパス」**をクリックします
2. すぐにそのサイトにリダイレクトされます
3. 5分後、ブロックが自動的に再開されます

### すべてのブロックを一時停止する

- ポップアップヘッダーのスイッチをOFFに切り替えます
- すべてのサイトが即座にブロック解除されます
- ONに戻して再有効化します

### パスワード保護（オプション）

バイパスボタンを押してしまう自分が信じられない？パスワードを設定しましょう：

1. ポップアップを開き → **⚙ / 🔒** → *パスワード保護* セクション、またはリストページの 🔒 ボタン
2. パスワードを設定（4文字以上）— パスワードはソルト付きハッシュとして**このデバイスにのみ**保存され、アップロードされることはありません
3. 以後、次の操作にはパスワードが必要です：
   - ブロックの停止（グローバルスイッチ）
   - ブロックページでの「5分間バイパス」
   - サイトの削除・リストの全消去
   - ブロック期間の編集
4. パスワードはいつでも変更・削除できます（現在のパスワードが必要）

> ⚠️ **パスワードを忘れると復元できません。** リセットリンクも復旧手段もバックドアもありません — 意図的な設計です。確実に覚えられるものを選んでください。

## プライバシー

- **declarativeNetRequest** — 宣言的ルールを使用してサイトをブロックします。ページコンテンツは読み取りません。
- **storage** — ブロックリストをローカルに保存します。データはアップロードされません。
- **パスワード（オプション）** — 設定した場合、ソルト付きハッシュのみをローカルストレージに保存。同期もアップロードもされません。忘れた場合は復元できません。
- **alarms** — 一時バイパスタイマーを管理します。バックグラウンドトラッキングはありません。
- **activeTab** — 拡張機能との操作時にのみ現在のタブにアクセスします。
- **ライセンス（オプション）** — 有料ライセンスを有効化した場合のみ：ライセンスキーとランダムなインストール識別子＋ブラウザメタデータが`api.annmax1983.com`に送信されてライセンスの有効化/検証が行われます。ブロックリスト、閲覧履歴、個人データが含まれることはありません。
- `<all_urls>`ホスト権限はdeclarativeNetRequestブロックルール用、およびライセンスサーバー用にのみ使用されます。トラッキングもアナリティクスもありません。無料ユーザーのデータがデバイスの外に出ることはありません。
