01

Everything it does

The core features at a glance.

01

Block any website: add a domain and every subdomain is covered. There is no limit on how many sites you block.

02

Timed blocks: 30 minutes, 1 hour, 2 hours, 4 hours, 8 hours, 24 hours or permanent. When the timer runs out the block lifts by itself — nothing to switch off and no reminder nagging you.

03

One-click pause: turn all blocking off for a lunch break, then turn it back on.

04

5-minute bypass: the reminder page has a bypass button for the times you honestly need one page. Five minutes later the block is back, automatically.

05

The reminder page shows how long is left, so the end of a block is visible rather than something you have to guess at.

06

Optional password lock: require a local password to pause blocking, use the bypass, remove a site, clear the list or change a timer. Only a salted hash is stored, on this device only. A forgotten password cannot be recovered.

Also included

  • Sync and backup: your blocklist and timers sync across the browsers signed into the same Chrome account. Export and import the whole list as a JSON file at any time.
  • Full list page: search your sites, see the remaining time on every timer, edit or reset it, and export the list in one place.
  • Add the current site: open the popup on a distracting page and add its domain in one click.
  • Six languages: English, Simplified Chinese, Japanese, German, Spanish and French. The interface follows your browser language automatically.
  • Quiet by design: vanilla JavaScript, no frameworks, no ads and no upsell screens standing between you and the block button.

02

Free vs Premium

The free tier is a complete tool, not a trial. Premium is optional.

Free

unlimited whole-site blocking, every block duration, global pause, 5-minute bypass, password protection, sync, export and import, and YouTube Shorts blocking.

Premium

Surgical Blocking on the other eleven sites. One key activates on two browsers, and removing it from one frees that slot again.

No licence is needed to block websites. Every free feature works without an account. Premium asks the licence server for a check about every two hours. If the server cannot be reached, Premium keeps working from the last verified state — a network failure never turns your paid features off.

Private by design

Your data stays on your device. No account, no analytics, no tracking. Read exactly what is stored and when the extension uses the network.
